1. Overview

Web Summary (Chrome Web Store name: A · Web Summary) is a browser extension that helps you decide whether to keep reading the active tab—then summarizes it using your own Google Gemini API key (BYOK — bring your own key).

There is no Web Summary backend server. The extension runs in your browser (side panel) and talks directly to Google’s Gemini API when you choose to summarize.

Single purpose: help you decide whether to read the current web page tab and summarize it for you.

2. Privacy Policy

What we do not collect

We run no servers, and nothing below is ever sent to us. We do not collect or log:

  • Page text or URLs you summarize
  • Generated summaries
  • Usage analytics tied to your browsing

What stays on your device

The only data the extension may persist locally is your Gemini API key (if you save it in Settings), your side panel UI language (English, Korean, or 中文), your Auto summarize preference (default OFF), your Auto summarize excluded domains list, whether you have completed your first summary (onboarding only), the time until which the gift notice stays hidden, and your summary history (see below). All are stored in chrome.storage.local on this browser only.

What is sent to third parties

When you tap Summarize this tab, or when Auto is ON and you stay on a tab for about 3 seconds, article text is sent directly from your browser to Google’s Gemini API using your API key. We do not receive a copy of that content.

That processing is governed by Google’s Privacy Policy and Gemini API terms.

  • On unpaid (free) tier keys, Google may use API prompts and responses to improve its products (see “Unpaid Services” in the Gemini API terms).
  • If you are in the EEA, UK, or Switzerland, Google recommends a billing-enabled (Paid) project—see section 8.

Page access

A content script is injected only when a summary is requested (manual button or Auto after dwell) on the active http(s) tab, to extract readable text. It does not stay active on every page for background summarization.

Summary results

Results (read/skip verdict, title, and three-line summary) appear in the side panel. The UI shows the source tab URL for reference. Output may include translation when your UI language differs from the article.

Summary history

  • What is saved: on a new install, each result is saved by default with the page address (including any query string), language, and time. Article text is not saved. With Auto on, this includes pages summarized automatically after about 3 seconds, so the list can show pages you visited. If you updated from a version without history, nothing is saved automatically until you turn it on in the history panel.
  • Where: only in chrome.storage.local on this browser. It is never sent to us or to Google. Reusing a saved summary makes no API call.
  • How long: up to the latest 200 pages, until you delete them or remove the extension. Pages marked Read later are removed last.
  • Your control: in the history panel you can turn off automatic saving (only pages you mark as Read later are then saved, and removing that mark also deletes the page from history), delete one entry, or delete everything.
  • Incognito: pages summarized in incognito windows are not saved.

Information received through gifts and contact

The extension does not collect gift records. The operator receives the information below only through payment service notifications or email.

  • Gifts: the sender name or display name shown by the payment service, amount, date, and message. Purpose: confirming receipt, recording the total received, handling returns, and tax handling. Basis: consent through sending voluntarily, and legal obligation for tax records. Retention: 5 years from receipt.
  • Contact: email address, content, and date. Purpose: replying and handling returns. Basis: consent through sending the email. Retention: 1 year after the matter is closed.

External services

  • KakaoPay and PayPal: you reach these services only when you press a button in the gift dialog or scan a QR code. Each company's privacy policy then applies.
  • QR library: bundled with the extension, so no request goes to cdnjs or any other external server.

Transfer abroad (email)

Contact email is received through Gmail. Recipient: Google LLC (United States). Items: email address and content. When and how: over the network when you send an email. Purpose: receiving and storing email. Period: the contact retention period above. If you prefer not to, you can use a project repository issue instead, but issues are public.

1. 概述

Web Summary（Chrome 网上应用店名称：A · Web Summary）是一款浏览器扩展，帮助您判断当前标签是否值得继续阅读，并使用您自己的 Google Gemini API 密钥（BYOK）进行摘要。

无 Web Summary 后端服务器。扩展在浏览器侧边栏运行，仅在您主动摘要时直接向 Google Gemini API 发送请求。

单一用途：帮助用户判断是否阅读当前网页标签，并为其提供摘要。

1. 개요

Web Summary(Chrome 웹스토어 이름: A · Web Summary)는 현재 탭을 계속 읽을지 판단하고, 사용자 본인의 Google Gemini API 키(BYOK)로 요약하는 Chrome 확장 프로그램입니다.

Web Summary 백엔드 서버는 없습니다. 확장은 브라우저 사이드패널에서 실행되며, 요약을 요청할 때만 Google Gemini API에 직접 연결합니다.

단일 목적: 현재 웹 페이지 탭을 읽을지 판단하고 요약을 제공하는 것.

요약 기록

  • 저장 항목: 새로 설치한 경우 기본 설정에서는 결과를 페이지 주소(쿼리 문자열 포함), 언어, 시각과 함께 저장합니다. 기사 본문은 저장하지 않습니다. Auto를 켜면 약 3초 머문 뒤 자동 요약된 페이지도 포함되므로, 방문한 페이지가 목록에 보일 수 있습니다. 기록 기능이 없던 버전에서 업데이트한 경우에는 기록 화면에서 직접 켜기 전까지 자동으로 저장하지 않습니다.
  • 저장 위치: 이 브라우저의 chrome.storage.local에만 저장하며 운영자나 Google로 보내지 않습니다. 저장된 요약을 다시 볼 때는 API를 호출하지 않습니다.
  • 보유 기간: 최근 200개 페이지까지, 직접 삭제하거나 확장을 제거할 때까지 보관합니다. 나중에 읽기로 표시한 페이지는 가장 나중에 지워집니다.
  • 사용자 설정: 기록 화면에서 자동 저장을 끄거나(이후 나중에 읽기로 표시한 페이지만 저장하며, 표시를 해제하면 해당 페이지도 기록에서 삭제), 한 건 또는 전체를 삭제할 수 있습니다.
  • 시크릿 창: 시크릿 창에서 요약한 페이지는 저장하지 않습니다.
